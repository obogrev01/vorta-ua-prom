FAQ

Часті запитання

Скільки коштує одна картка? ▼
Від 3 грн (~$0.08) для Prom.ua до 6 грн (~$0.15) для обох платформ + соцмережі. Ціна залежить від обраного тарифу.
Чи є безкоштовний пробний період? ▼
Так — 3 картки безкоштовно одразу після реєстрації. Без прив'язки картки.
Як працює автозаповнення Prom.ua? ▼
Натискаєш кнопку «Автозаповнити» — Vorta відкриває форму додавання товару на Prom.ua і автоматично заповнює всі доступні поля: назву, опис, ціну, артикул, SEO.
Якою мовою генерується контент? ▼
Весь контент генерується українською мовою. Бренди, моделі та технічні назви залишаються в оригіналі.
Що таке PRO тариф зі своїм API ключем? ▼
Ти підключаєш власний Anthropic API ключ — ми беремо мінімальну сервісну комісію $0.04/картка. Ідеально для тих хто генерує 200+ карток на місяць.
Як довго діє реферальна знижка? ▼
Постійно поки твій пост активний у соцмережах. Видалив пост — знижка автоматично скасовується. Відновив — знижка повертається.
